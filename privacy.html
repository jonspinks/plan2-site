Privacy Policy

For the rclone installation described on the homepage. Effective 17 September 2026.

Who this covers

This policy applies to a private installation of the open-source program rclone, operated by Jon Spinks for personal use. The application has a single user, who is also its operator and the owner of the Google Account it connects to. It is not offered to other people.

What data is accessed

With the operator's consent, the application uses the Google Drive API to read and write the files and folders in the operator's own Google Drive. It requests the drive scope, which is needed to present Drive as an ordinary folder on the operator's computer. It does not access Gmail, Calendar, Contacts, or any other Google service, and it does not access any other person's account.

How the data is used

Drive content is transferred directly between Google's servers and the operator's own computer, so that Drive files can be opened, edited, and saved like local files. The data is used for no other purpose. In particular it is never sold, never shared with third parties, never used for advertising, and never used to train machine-learning models. No human other than the operator reads it.

Where the data is stored

Files stay in Google Drive and on the operator's computer. A local cache of recently used files is held on that computer's encrypted disk and cleared automatically. The OAuth tokens that authorise access are stored in a permissions-restricted configuration file on the same computer. Nothing is uploaded to any server belonging to the operator, because there is no such server.

Sharing

No Google user data is transmitted to anyone. The only parties involved in a transfer are Google and the operator's own computer.

Limited Use

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

The operator can revoke the application's access at any time at myaccount.google.com/permissions. Revoking access immediately stops all further data transfer. The local cache and stored tokens are removed by deleting them from the computer, which ends all retention of Google user data.

Changes

If this setup changes in a way that affects the above, this page will be updated and the effective date changed.
