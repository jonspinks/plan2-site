Personal apps on plan2.co

Personal software, not a public service.

Google requires every OAuth application to publish a homepage and a privacy policy, including applications with exactly one user. These are the homepages of two private installations, each used only by its owner on a personal laptop.

rclone

rclone is open-source software for synchronising files with cloud storage. This installation runs on a personal laptop and mounts one Google Drive account as a folder on that machine. It is used only by its owner. There is no website to sign up for, no service offered to anyone else, and no server that receives anyone's data.

rclone privacy policy

Omarchy Calendar

Omarchy Calendar is an open-source calendar for the Omarchy Linux desktop. This installation uses the Google Calendar API to show one Google account's events in the desktop's calendar, remind its owner before meetings, and let them manage events from the desktop. The same applies: one user, no service offered to anyone else, and no server that receives anyone's data.
